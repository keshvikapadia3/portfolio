# Student Portfolio

A responsive and reusable **Student Portfolio Website** built using **React** and **Vite**. This project demonstrates React component architecture, reusable functional components, and props, as required for Practical 1 of the Advanced Web Development Frameworks (AWDF) course.

---

## 📌 Project Overview

The application is designed as a personal portfolio for a student. It follows a component-based architecture where each section of the website is developed as an independent and reusable React component.

The project includes:

- Reusable Header Component
- Reusable Navbar Component
- About Section
- Skills Section (using Props)
- Projects Section
- Reusable Footer Component

---

## 🚀 Features

- Built using React + Vite
- Component-based architecture
- Reusable functional components
- Dynamic rendering using props
- Skills displayed using JavaScript `map()`
- Responsive and modern UI
- Clean and maintainable code structure

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/student-portfolio.git
```

Move into the project directory

```bash
cd student-portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open the browser and visit

```
http://localhost:5173
```
